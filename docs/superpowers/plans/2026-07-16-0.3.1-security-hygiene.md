# 0.3.1 Security Hygiene Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Release `0.3.1` with current source-built Docker distribution intact, current validation behavior preserved, and dependency/security checks strengthened.

**Architecture:** Keep the CLI, Compose file, and adapter build contexts unchanged. Generate Ajv standalone validators during development and commit the generated TypeScript so published runtime code does not load Ajv or compile schemas dynamically. Add Go vulnerability scanning to the existing adapter CI job.

**Tech Stack:** TypeScript 7, Node.js 22/24, Ajv standalone generation, Vitest, pnpm, Go 1.26, govulncheck, GitHub Actions.

## Global Constraints

- Do not add hosted services, prebuilt images, or GHCR dependencies.
- Preserve all existing adapter protocol and external manifest validation behavior.
- Keep generated validators reproducible and checked by CI.
- Publish only after the complete local test, package, security, and Docker proof passes.
